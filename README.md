# Times Table Quiz

A command-line Python quiz. Choose a times table from 1 to 12, answer 12 questions,
and get your score at the end. You can play as many rounds as you like.

## How to run
Requires Python 3.

    python quiz.py

## Features
- Input validation: rejects non-numbers and tables outside 1–12
- Score tracking that resets each round
- Play-again option

## What I learned
- Writing reusable helper functions
- Handling errors with try/except
- Nested loops and program flow
